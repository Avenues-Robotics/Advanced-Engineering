You are finally ready to write some code for a competition robot!
For this last FTC Java assignment, create a new OpMode inside your auto package named `LeaveAndPark.java`.  Design a simple program that scores your team 10 points by:
1. Start in a legal location
2. LEAVE the starting position \[5 points\]
3. Stop in the LOADING ZONE \[5 points\]
Make sure you comment your code!

## Rubric
### Software Implementation
<columns>
	<column ratio="50">
		**Proficient**
		- Classes with correctly structured fields, constructors, and methods that compile without errors and behave as intended when run.
		- When code doesn't work, a systematic debugging process is followed: the failure reliably reproduced, the responsible section of code isolated (for example, with telemetry/print statements or a debugger), the specific cause fixed, and the fix verified to actually resolve the original failure.
		- Code successfully deployed to the robot controller and confirmed to run as intended on the actual hardware.
		- ~~Code committed to version control regularly with messages that describe what changed and why, rather than committed in one large, undocumented batch.~~

	</column>

		**Advanced**
		In addition to Proficient…
		- Intermittent or hardware-dependent failures (something that only happens sometimes, or only on the robot and not in testing) debugged by forming a specific hypothesis about the cause and designing a test that would confirm or rule it out.
		- Code organized and named so a teammate could read and correctly modify it without a verbal explanation, with comments added where the reasoning behind a piece of code isn't self-evident from the code itself.
		- ~~Branches used to develop a feature or fix without disrupting the team's working code, with changes merged back cleanly and simple conflicts resolved as they arise.~~
		- ~~Common deployment failures recognized and prevented (code that isn't saved to the right location, a build that succeeds on a laptop but doesn't match what's on the robot, forgetting to pull a teammate's changes before running).~~
