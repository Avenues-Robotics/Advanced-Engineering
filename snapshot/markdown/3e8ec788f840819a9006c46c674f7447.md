1. Sign in to [FTCSIM](https://ftcsim.org/course/fzapjibwdkf/) and navigate to the Movement course.
2. Start the field **3 - Half Moon**
3. Click the OnBot Java tab.
4. Replace ALL of the code with your solution to the previous challenge 2 - Rearward
5. Create a new method to handle rotating the robot.  Copy the `public void drive(double speed, int ticks)` method. Paste the copy under the original and rename it **`public void rotate(double speed, double degrees)`**
6. Fix the code inside the new `rotate(speed, degrees)` method to make the robot rotate the given number of `degrees` (right for positive degrees, left for negative degrees). For example, calling `rotate(0.5, -90)` would rotate the robot 90 degrees to the left. A line of code like this will be helpful:
	- `int ticks = (int) (degrees * 11.1)`
	- The (int) after the equal sign converts the decimal number to an integer since the `setTargetPosition(ticks)` method requires an integer number.
7. Use the `drive(double speed, int ticks)` and the `rotate(double speed, double degrees)` methods to complete the challenge.
