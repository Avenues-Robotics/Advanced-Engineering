## Part 1
Use the FTCSIM website to learn the basics of Java for FTC Robotics,
### Getting Started with Java Programming
In this module you will use the [FTCSIM](https://ftcsim.org/) website to program a basic FTC robot to complete a series of puzzles. The puzzles will grow in complexity as you learn more.
The assignments in this module should give you most of the information you need to complete them successfully and teach you about the basics of programming an FTC robot in Java. You will learn how to:
- Map hardware to objects in code
- Store data and objects as variables
- Write and call methods
- Use encoders to precisely control motors
- Use a color sensor
- Use a distance sensor
If you find yourself stuck on some of the language or structure of your programs there are a couple of resources you can use to help:
- your teachers (Ms. Patricia, Ms. Chan, and Mr. Carpenter)
- [Game Manual Zero's Getting Started with Software](https://gm0.org/en/latest/docs/software/getting-started/index.html)
- Google - a well formed search question will usually get you a good explanation
- AI - a well formed request to ChatGPT or another AI tool will usually get you a good explanation
