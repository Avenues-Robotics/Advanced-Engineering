### Start an Android Studio Project with the FTC Robot Controller SDK (software development kit)
#### Part 1: Download the SDK
1. Open Android Studio and click **Get from VCS**.
2. Version control: `Git`. URL: `https://github.com/FIRST-Tech-Challenge/FtcRobotController.git`
3. Directory: `/Users/YOUR_USER_NAME/Documents/Robotics/YOUR_REPO_NAME`
4. Click **Clone**, then **Trust Project**.
#### Part 2: Create Your Empty Repository on GitHub
1. Go to [**https://github.com/newLinks to an external site.**](https://github.com/new).
2. Owner: `Avenues-Robotics`. Name: your team or personal name (e.g., `Ruckus-2026` or `Frank-R-2026`).
3. **Do not** add a README, .gitignore, or license. The repo must be completely empty.
4. Click **Create repository** and copy the HTTPS URL.
#### Part 3: Point Your Project at Your New Repository
1. In Android Studio, go to **Git → Manage Remotes…**
2. Select `origin`, click the **pencil (edit)** icon, and change the name to `upstream`. Leave the URL alone. Click **OK**.
3. Click **+** and add:
	- Name: `origin`
	- URL: the URL you copied in Part 2
4. Click **OK**.
5. Go to **Git → Push…**. Make sure it says `master → origin : master`, then click **Push**. If asked, log in to GitHub.
6. Refresh your repo page on GitHub. You should see all the files on `master`.
#### Getting SDK Updates Later
When a coach says there’s an update, go to **Git → Fetch**, then **Git → Merge…** and choose `upstream/master`.
