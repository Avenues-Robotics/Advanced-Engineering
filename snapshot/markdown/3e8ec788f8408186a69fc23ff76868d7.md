### Install Android Studio
You're going to need some help with this step.
1. Download the latest version of Android Studio here: [https://developer.android.com/studio](https://developer.android.com/studio)
2. You need some permissions from tech to get Android Studio working.  If you have any issue, go to the tech office. They will get your MacBook configured to allow you to use Android Studio.
3. Run the Android Studio installer, selecting all of the default options.
### Install Git from Self Service
1. Sign into Company Portal and find the Git installer
2. Click install
### Start an Android Studio Project with the FTC Robot Controller SDK (software development kit)
1. Open Android Studio
2. You are going to create a new Project using the `Get from VCS` button.
3. VCS stands for version control system. In this case you are going to get the project from the FTC Github account.
	- In the **Version control** box, choose `Git`
	- Paste this URL into the **URL box**: `https://github.com/FIRST-Tech-Challenge/FtcRobotController.git`
	- In the Directory box, you should store your project as follows:
		- `/Users/YOUR_USER_NAME/Documents/Robotics/DECODE`
	- Click `Clone` to complete the download. Then click `Trust Project`.
### Explore the Sample Code
The FTC SDK comes with 50+ samples that are thoroughly documented to show core concepts and the use of specific hardware. Let's look at one sample to get an idea of what we can learn.
1. In the browser in the left sidebar, navigate to the **external.samples** package:
	- FtcRobotController
		- java
			- org.firstinspires.ftc.robotcontroller
				- **external.samples**
2. Open the **BasicOpMode_Linear** class
3. Explore the code and read the comments.
