### Create the PIDF Class
1. In Android Studio, right click on **TeamCode \>\> java \>\> org.firstinspires.ftc.teamcode** and select **New \>\> Package**
2. Name the new package `org.firstinspires.ftc.teamcode.utility`
	- The **utility** package will hold your PIDF controller and other classes that don't directly control hardware.
3. Right click on the **utility** package and select **New \>\> Java Class**. Name the class `PIDF`.

### Finish the Code
Complete the class so that `update()` returns the PIDF output for one pass through the control loop. As you work, think about:
- **Which values have to survive from one call to the next?** Anything the controller needs to remember between passes (like the running integral sum, the last error, and the loop timer) has to be an instance variable, not a local variable inside `update()`.
- **What should happen inside the tolerance?** When the error is smaller than the tolerance, the mechanism is close enough. Decide what `output` should be in that case, and whether the feedforward term should still apply. (Should a slide holding a height turn its motor off?)
- **How will other code know the mechanism has arrived?** Consider adding a public method, like `atTarget()`, that returns `true` when the last error was within the tolerance.
