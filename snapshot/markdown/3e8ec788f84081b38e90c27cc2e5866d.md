### Using the distance sensor
The first few steps here show the general pattern for adding a new piece of hardware to your code. A similar process is used to add a new motor, a sensor, or to use the Control Hub's internal IMU.
### Step 1
At the top of your `MyFIRSTJavaOpMode` class, under the line
```java
ColorSensor color; 
```
define a new new class member named color as follows:
```java
DistanceSensor distance;
```
This creates a new variable named `distance` of the type `DistanceSensor`.
### Step 2
Inside the `runOpMode()` method, add the following line under the similar lines used to define the motor hardware:
```java
distance = hardwareMap.get(DistanceSensor.class, "distance1");
```
This assigns the hardware named `distance1` on the robot configuration to the variable named `distance`.
### Step 3
At any point inside the the `runOpMode()` method, you can run any of the following methods to get information about what the robot's color sensor is detecting. Each of these will return a decimal number (technically a `double`) giving the distance to the nearest object in front of the robot in different units.
```java
distance.getDistance(DistanceUnit.CM);
distance.getDistance(DistanceUnit.INCH);
distance.getDistance(DistanceUnit.METER);
distance.getDistance(DistanceUnit.MM);
```
Note that if you had named your distance sensor something else in step 1 and 2, say `distance2`, then you would then use `distance2.getDistance(DistanceUnit.CM)` to get the red value from the sensor.
