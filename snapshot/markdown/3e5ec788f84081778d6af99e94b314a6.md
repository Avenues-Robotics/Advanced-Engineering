# 1. Robot Overview
Same robot as the proficient-level sample: a four-wheel mecanum drivetrain, a front roller intake, a linear slide lift, and a claw outtake mounted on the lift. Autonomous drives to a spike mark, drops a purple pixel, drives to the backdrop, raises the lift, deposits a yellow pixel, and parks. Teleop splits control across two drivers. Nothing about the robot changed for this version, only how precisely the software structure is specified.

*Legend: dashed line with an open triangle means implements, a filled diamond means owns (composition), and an open arrow means calls (association).*
All four subsystems need the same thing from OpMode: get called once per cycle. That's what the Subsystem interface formalizes.
```javascript
// Before: OpMode calls each subsystem by name
drivetrain.update()
intake.update()
lift.update()
outtake.update()

// After: OpMode holds a list of Subsystem
for each s in subsystems:
    s.update()
// A fifth mechanism later means one new line in the list, the loop itself never changes.
```

# 5. Autonomous Main Loop
```javascript
state = DRIVE_TO_SPIKE

loop():
    switch(state):
        case DRIVE_TO_SPIKE:
            drivetrain.driveTo(spikeMarkPose)
            if drivetrain.atPose(): state = DROP_PURPLE

        case DROP_PURPLE:
            outtake.release()
            if outtake.isEmpty(): state = DRIVE_TO_BACKDROP

        case DRIVE_TO_BACKDROP:
            drivetrain.driveTo(backdropPose)
            if drivetrain.atPose(): state = RAISE_LIFT

        case RAISE_LIFT:
            lift.setTarget(BACKDROP)
            if lift.atTarget(): state = DEPOSIT_YELLOW

        case DEPOSIT_YELLOW:
            outtake.release()
            if outtake.isEmpty(): state = PARK

        case PARK:
            drivetrain.driveTo(parkPose)
            if drivetrain.atPose(): state = DONE

        case DONE:
            // autonomous complete, no further action
```
*Same DRIVE_TO_SPIKE through DONE sequence as the proficient-level flowchart, now every transition condition is a real typed method call against the class structure above, not an edge label on a box.*
# 6. Teleop Main Loop
```javascript
loop():  // repeats every cycle, about 20 ms

    drivetrain.drive(gamepad1.leftStick, gamepad1.rightStick, gamepad1.turn)

    if gamepad2.rightTrigger: intake.setState(INTAKING)
    else if gamepad2.leftTrigger: intake.setState(REVERSING)
    else: intake.setState(IDLE)

    if gamepad2.dpadUp: lift.setTarget(BACKDROP)
    else if gamepad2.dpadDown: lift.setTarget(HOME)
    lift.update()

    if gamepad2.aButton and lift.atTarget() and not outtake.isEmpty():
        outtake.release()
    else if gamepad2.bButton:
        outtake.grab()

    telemetry.update()
```
*The release guard now checks both lift.atTarget() and not outtake.isEmpty(), a driver pressing release with nothing in the claw does nothing, instead of just gating on lift height like the earlier version.*
