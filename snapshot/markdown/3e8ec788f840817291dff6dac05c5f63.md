### Using the color sensor
The first few steps here show the general pattern for adding a new piece of hardware to your code. A similar process is used to add a new motor, a sensor, or to use the Control Hub's internal IMU.
### Step 1
At the top of your `MyFIRSTJavaOpMode` class, under the line
```java
DcMotor motorRight; 
```
define a new new class member named color as follows:
```java
ColorSensor color;
```
This creates a new variable named `color` of the type `ColorSensor`.
### Step 2
Inside the `runOpMode()` method, add the following line under the similar lines used to define the motor hardware:
```java
color = hardwareMap.get(ColorSensor.class, "color1");
```
This assigns the hardware named `color1` on the robot configuration to the variable named `color`.
### Step 3
At any point inside the the `runOpMode()` method, you can run any of the following methods to get information about what the robot's color sensor is detecting. Each of these will return integer between 0 and 255. The higher the value the more of that color is being detected.
```java
color.red()
color.green()
color.blue()
```
Note that if you had named your color sensor something else in step 1 and 2, say `color2`, then you would then use `color2.red()` to get the red value from the sensor.
### Using Telemetry to get information from the robot
As you drive over the red/blue square, you will need to know what values the color sensor is detecting. The red square may be pure red `color.red() = 255` or some combination of red, green, and blue.
Write some code to stop the robot on top of the red/blue square. Then use the code below to print some information to the telemetry panel. You can click Show Telemetry at the top right corner of the screen to see the output. On the real robot, this information is shown on the Driver Hub.
```java
// Add a comment to explain what the two arguments in the addData() method do
telemetry.addData("red", color.red());
telemetry.addData("green", color.green());
telemetry.addData("blue", color.blue());
telemetry.update();
```
