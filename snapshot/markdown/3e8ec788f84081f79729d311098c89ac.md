This module will use a simple FTC Test Bot to help you learn the basics of configuring a robot and running a basic autonomous OpMode.
![](media/576946b9a46a7819.png)
<empty-block/>
The Test Bot uses four mecanum wheels powered by four motors. Each motor is connected to the Rev Control Hub--the robot's computer--with two wires. The thicker red/black wire is the **power cable** that supplies up to 12 Volts to the motor. The thinner black/red/white/blue cable (technically a JST cable) is the **encoder cable** which carries the rotation measurements taken by the motor's built in quadrature encoder back to the Control Hub.
Wondering how the encoders measure the motor's rotation? Check out these videos: [How does an encoder work?](https://www.youtube.com/watch?v=_jTqVncUkCI) and [What is quadrature and how is it used?](https://www.youtube.com/watch?v=NfX0uOaXQ3c)
To configure the robot's hardware to be used by your code, you need to connect to the robot with a Driver Hub.
Make sure the robot has a battery plugged into it's power switch and turn on the switch. You should see the Control Hub lights come on. The robot is now creating its own wifi network that you can connect to with a Driver Hub or a computer.
Grab a Driver Hub and navigate to the wifi settings. Connect to the Test Bot's wifi network.
