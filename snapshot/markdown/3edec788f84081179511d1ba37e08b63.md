The Robot Controller used in FTC is programmed in Java, the same language used by professional software engineers to build Android apps, web servers, and large enterprise systems. Learning Java for FTC will not only help your team in the robot games, but will give you real-world programming skills and a familiarity with  programming language used by professionals in dozens of applications.
Before you program a real robot, you will learn the fundamentals in FTCSIM, a free browser-based simulator that runs a virtual FTC robot on a virtual field. A simulator lets you experiment, make mistakes, and run your code dozens of times without charging batteries, fixing wiring, or chasing a robot across the room. Professional engineers use simulation the same way: to test ideas quickly and cheaply before they touch hardware.
These tutorials build your Java skills one step at a time. The first five use the Movement course to teach you how to map hardware to objects in code, store data in variables, write and call your own methods, and use encoders to precisely control motors. The last four use the FTC Sensors course to add a color sensor and a distance sensor, read their values with telemetry, and make decisions with `if...else` statements. Each challenge starts with your solution to the previous one, so work through them in order. The code you finish with in FTC Java 5 becomes the starting point for programming a real robot in the next set of tutorials.
If you get stuck, ask your teachers, check [Game Manual Zero's Getting Started with Software](https://gm0.org/en/latest/docs/software/getting-started/index.html), or try a well-formed search or AI question that asks for an explanation, not just an answer.
