# 1. Robot Overview
This robot has four mechanisms: a four-wheel mecanum drivetrain, a front roller intake that collects pixels from the field, a linear slide lift that raises a scoring mechanism to backdrop height, and a claw-style outtake mounted on the lift that holds and releases pixels. Autonomous drives to a spike mark, drops a purple pixel, drives to the backdrop, raises the lift, deposits a yellow pixel, and parks. Teleop lets one driver control the drivetrain and a second driver control intake, lift, and outtake.

<callout color="gray_bg">
	*Teacher note: Lift and Outtake are separate classes even though they're physically stacked on the same mechanism, because they're controlled independently: a driver can raise the lift without opening the claw, and vice versa. Keeping them separate means a change to claw timing never touches lift code.*
</callout>

# 5. Autonomous Main Loop
![](media/9f5d37ddd6c1c9b3.svg)
*Each cycle, the loop checks the current state's exit condition. If it's met, the state advances and the next subsystem command is issued once. Drivetrain, Lift, Intake, and Outtake are only ever called with a single command per state, the state machine is what sequences them, the subsystems themselves don't know what step of autonomous they're in.*

# 7. Design Rationale
The four subsystems match the four mechanisms on the robot exactly, one class per motor group that moves together as a physical unit. Drivetrain is separate from everything else because it's the only subsystem the primary driver touches, and it has no scoring logic in it at all. Intake and Outtake are both about handling a pixel, but they're separate classes because they act on the pixel at different points, Intake never runs at the same time Outtake does, and combining them would mean one class doing two unrelated jobs. The dashed line from Lift to Outtake in the block diagram is the one place two subsystems talk to each other directly, Outtake checks Lift.atTarget() so a driver mashing the release button can't drop a pixel while the lift is still moving.
