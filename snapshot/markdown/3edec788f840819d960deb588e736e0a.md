A simulator is a great place to learn, but real robots are messier. Wheels slip, batteries sag, motors are not perfectly matched, and the robot has to be configured, connected, and loaded with your code before it can do anything at all. The engineering work of robotics programming happens in the gap between code that works in simulation and code that works reliably on hardware.  These tutorials will get you set-up to start the real software implementation.
You will move from FTCSIM's browser-based OnBot Java editor to Android Studio, the professional development environment used by Android app developers and by competitive FTC teams. Along the way you will configure a test bot's hardware on the Driver Hub, connect your laptop to the robot over Wi-Fi, and install Panels, a tool that lets you watch telemetry and tune values from your computer while the robot runs. Then you will port your FTCSIM drive code to a four-motor mecanum drivetrain, calibrate it so the robot drives in real centimeters and degrees, and reorganize it into a reusable Drive class so every future OpMode can share it. You will finish by writing a Leave and Park autonomous OpMode that scores points in a real match.
The early tutorials are mostly setup and can be frustrating: installs need permissions, Wi-Fi connections drop, and builds fail for reasons that have nothing to do with your code. That is normal. Read the troubleshooting sections carefully, ask for help early, and keep notes on what fixed each problem so you and your teammates can solve it faster next time. Work through the sequence in order, since each tutorial depends on the one before it.
